    The reader of rh index does not use Lean. It finds a name in a declaration and resolves it with the namespaces and the open commands. A strong edge is a name that resolves to one declaration. A weak edge is a name in dot notation, which can go to more than one declaration. So the numbers are close to the numbers of Lean, but they are not exact. The data is in api/code.json.
